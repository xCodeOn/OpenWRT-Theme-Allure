# Allure 1.8 — принципы дизайна

- Отступы: 8 / 12 / 16 / 24 / 30 px. Поля и кнопки: высота 38–43 px (на смартфоне ~44 px).
- Контент: ширина до 1380 px; боковое меню 260 px; верхняя панель 64/58 px.
- Карточки: радиус 22 px, мягкая граница и лёгкая тень; вложенные карточки менее контрастные.
- Цвета: оригинальные фиолетовые оттенки Allure в `allure-refined.css`, автоматическая тёмная/светлая схема через `data-darkmode`.
- Вкладки: не переносить строки, использовать горизонтальную прокрутку.
- Таблицы: если все строки прямоугольные и колонок 2–6, на телефоне включаются визуальные карточки без изменения структуры таблицы; иначе — прокрутка.
- Терминал / Ace / Monaco / CodeMirror исключаются из общего оформления.
- Для сторонних приложений можно использовать `data-allure-ignore`, чтобы исключить вложенный компонент из адаптации.

Референс: `luci-theme-aurora` от eamonxg (Apache 2.0) — анализ визуальных принципов, без копирования его исходных файлов. Программные проверки не заменяют тесты на настоящем маршрутизаторе.
