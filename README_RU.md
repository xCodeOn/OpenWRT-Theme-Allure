# Allure 1.8.0 — обновлённый дизайн

В этой версии все обычные формы LuCI оформляются единообразно, как и новые вкладки сторонних плагинов (если они используют стандартные HTML-компоненты). Сложные встроенные веб-приложения могут требовать отдельных стилей.

**Обновление:** скопируйте папку `Allure_Router_OpenWrt25` на роутер в `/tmp`, выполните `cd /tmp/Allure_Router_OpenWrt25 && sh install.sh` под root и затем очистите кэш браузера. Проводное подключение и резервная копия настроек рекомендуются перед любой заменой темы.

**Возврат стандартной темы по SSH:** `uci set luci.main.mediaurlbase='/luci-static/bootstrap'; uci commit luci; rm -f /tmp/luci-indexcache; /etc/init.d/uhttpd reload`.

Структура оформления: `allure.css` — базовый каркас и панель мониторинга; `allure-refined.css` — все LuCI-элементы и мобильная адаптация; `allure-refined.js` — осторожная адаптация динамических вкладок/таблиц; `allure-auth.css` — анимированный экран входа.

Новое оформление вдохновлено чёткой сеткой и иерархией Aurora, но исходники Aurora не включены. Скриншоты в `preview/screenshots/` созданы на демонстрационных данных. На роутере Cudy TR3000 эта сборка не проверена.

**Ниже сохранены исторические примечания к старым выпускам.** В 1.8 файлы `allure-luci-polish.css`, `allure-mobile-fixes.css`, `allure-mobile.js` и `allure-adaptive.css` удалены; используйте `allure-refined.css` и `allure-refined.js`.

## Allure 1.7.1 — анимация экрана входа

Сделана более выразительная, но мягкая анимация ночного пейзажа: медленные ленты северного сияния, мерцающие частицы, движение отражений в озере, деликатная подсветка стеклянной панели и блик на кнопке входа. Проверка: `preview/login-preview.html?theme=dark&lang=ru`. Изменения ограничены экраном входа.

# Allure Router UI v1.7 — автоматическое оформление новых компонентов LuCI

**Что нового:** универсальный слой совместимости для большинства стандартных и сторонних страниц LuCI. Новые пакеты, использующие обычные элементы LuCI/HTML, автоматически получают общие цвета, скругления, отступы и адаптивное оформление. JavaScript отслеживает динамически добавленные вкладки, панели действий и таблицы без вмешательства в сетевые запросы, настройки, значения форм и обработчики приложений.

**Ключевые файлы:** `htdocs/luci-static/allure/allure-adaptive.css` и `allure-adaptive.js`. Они включены в шаблон `ucode/template/themes/allure/header.ut` после базовых стилей. Добавлены недостающие SVG-иконки в меню для AdGuard Home, Docker, VPN и ряда других компонентов. Неизвестным пунктам по-прежнему назначается нейтральная иконка.

**Проверка без роутера:** `preview/interface-new-plugin.html` показывает демонстрационные карточки AdGuard Home и Docker Manager, а кнопка «Загрузить интерфейс» вставляет тестовую форму, таблицу и вкладки в DOM на лету. Скриншоты хранятся в `preview/screenshots/Allure_v1.7_*`. Демонстрация НЕ подключена к настоящим службам роутера.

**Ограничения:** это универсальная тема, не модификация исходников каждого плагина. Специальные веб-интерфейсы, iframe, закрытый Shadow DOM, canvas, терминалы и самостоятельно нарисованные интерфейсы не гарантируют полного совпадения с Allure. Сложные таблицы остаются прокручиваемыми по горизонтали, когда карточный вид мог бы нарушить работу компонента. Переводы сторонних приложений зависят от установленных пакетов локализации. **На физическом Cudy TR3000 v1.7 не тестировалась.**

Установка: распаковать в папку `Allure_Router_OpenWrt25`, скопировать на роутер, выполнить `sh install.sh`, затем обновить страницу с очисткой кэша. Откат: `sh uninstall.sh` либо переключение на Bootstrap. Сначала рекомендуется резервная копия конфигурации OpenWrt.

Подробнее для разработчиков плагинов: `COMPATIBILITY_RU.md`.

# Allure Router UI v1.6.1 — мобильные исправления

Обновление основано на скриншотах Forkop 2.0.0 на iPhone. В Allure добавлены `allure-mobile-fixes.css` и `allure-mobile.js`. Существующие файлы LuCI/настройки роутера не меняются. Скрипт только проставляет подписи столбцов у простых таблиц (2–6 колонок), не меняет значения и не перехватывает события кнопок. Если сложная таблица не подходит для представления карточками, она остаётся горизонтально прокручиваемой.

**Что исправляется:** табы в один прокручиваемый ряд, мобильная карточная таблица правил (там, где есть обычные заголовки), отступы кнопок и форм, более компактная верхняя панель, запас места снизу на iOS Safari.

**Важно:** Forkop 2.0.0 может использовать собственные стили и нестандартные компоненты; без доступа к фактическому HTML работающего роутера нельзя гарантировать, что любая его страница будет полностью переоформлена. Нестандартные таблицы внутри Shadow DOM/iframe не изменяются. Автономное превью `preview/interface-forkop-mobile.html` — воспроизведение проблемной компоновки с демонстрационными данными, не снимок с роутера.

Проверка на роутере: открыть Forkop → Секции → Статус, провести пальцем по строке вкладок, убедиться, что кнопка «Изменить» видна и доступны все действия. Если стили не применились — обновить страницу с очисткой кэша.

## Требования

OpenWrt **25.12+** с актуальной LuCI на ucode, включая семейство Cudy TR3000 с MT7981. Не подходит для оригинальной заводской CudyOS. Зависимости: `luci-base`, `luci-mod-status`, `luci-theme-bootstrap`, `rpcd-mod-ucode`.

Русский перевод стандартных страниц LuCI обеспечивается **отдельными системными языковыми пакетами**. Установите доступные для вашей версии (`apk add`):

```sh
apk update
apk add luci-i18n-base-ru luci-i18n-mod-status-ru luci-i18n-mod-network-ru luci-i18n-mod-system-ru
```

Если одного из этих пакетов нет в репозитории вашей сборки, установите доступные по одному. Это не мешает переводу собственной оболочки Allure и Dashboard. Сторонние приложения должны иметь свои RU-переводы; тема не может перевести их произвольные страницы автоматически.

## Установка / обновление

1. Распакуйте ZIP локально и скопируйте папку по SSH (замените IP):

```sh
scp -r Allure_Router_OpenWrt25 root@192.168.1.1:/tmp/
```

2. При первом запуске убедитесь, что зависимости установлены:

```sh
apk update
apk add luci-base luci-mod-status luci-theme-bootstrap rpcd-mod-ucode
```

3. На роутере:

```sh
cd /tmp/Allure_Router_OpenWrt25
sh install.sh
```

Откройте `/cgi-bin/luci/admin/status/allure` и обновите страницу с очисткой кэша (`Ctrl+Shift+R` / `Cmd+Shift+R`). При обновлении старой версии Allure повторите `sh install.sh`; **после обновления очистите кэш браузера (Cmd+Shift+R / Ctrl+Shift+R)**, чтобы загрузились новые SVG-иконки и экран входа. Установщик не меняет сетевые настройки, Wi-Fi, firewall и прошивку.

**Вернуть стандартную тему без удаления:**

```sh
uci set luci.main.mediaurlbase='/luci-static/bootstrap'
uci commit luci
/etc/init.d/uhttpd reload
```

**Полное удаление:** `sh uninstall.sh` из папки исходников.

## Диагностика температур — важно

На Cudy TR3000 наличие датчика внутри чипа **не означает**, что ваша версия ядра OpenWrt предоставляет его значения. Тема не может прочесть аппаратное значение в обход отсутствующего драйвера. Не устанавливайте случайные драйверы от других моделей: можно повредить работу роутера.

Выполните по SSH:

```sh
cd /tmp/Allure_Router_OpenWrt25
sh tools/allure-diagnostics.sh
```

Или вручную:

```sh
ubus -v list luci.allure
ubus call luci.allure sensors
for f in /sys/class/thermal/thermal_zone*/temp /sys/class/hwmon/hwmon*/temp*_input; do
  [ -r "$f" ] && { echo "$f"; cat "$f"; }
done
```

- Если `ubus call luci.allure sensors` выдаёт ошибку объекта/метода — проверьте `rpcd-mod-ucode`, файл `/usr/share/rpcd/ucode/allure.uc`, права чтения и `/etc/init.d/rpcd restart`.
- Если RPC возвращает `status: "no-kernel-sensors"`, а системные каталоги не содержат значений — причина в сборке ядра / device tree / поддержке thermal-контроллера. Требуется прошивка с поддержкой датчика; тема сама аппаратную температуру получить не может.
- Если `sensors` содержит числовые `celsius` — Allure показывает их на главной. Точки на демо-превью синтетические и не доказывают работоспособность на устройстве.

### Безопасность

RPC-функция только читает фиксированные пути `/sys`; никакого выполнения команд из интерфейса и изменения сетевых настроек. При отсутствии датчика нули/вымышленные градусы не показываются.

### Проверка экрана входа

1. После установки откройте LuCI и выйдите из текущей сессии (Log out). Откроется новый `sysauth.ut` экран.
2. Внизу карточки выберите тему; настройки сохраняются в этом браузере.
3. Если вход вызывает ошибку, верните bootstrap командой из раздела отката.
4. Анимация автоматически отключается при настройке ОС «уменьшение движения».

**Ограничение:** проверить вход и аппаратную температуру на конкретном Cudy TR3000 в этом окружении невозможно. Избегайте обновления роутера без резервной копии конфигурации.
