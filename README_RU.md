# Allure Router UI 2.0 — переработанная тема OpenWrt 25.12+

## Что изменено

Версия 2.0 переработана после анализа дефектов на реальных скриншотах LuCI/Forkop. Конфликтующие `allure-refined.css`, `allure-refined.js` и `allure-adaptive.js` полностью удалены из поставки и из шаблона. Их заменила одна совместимая таблицами `allure-system.css`.

Главная причина старых дефектов: обобщённые селекторы `:is(table,.table)` и изменения `display`, `width`, `grid` для элементов LuCI `.table/.tr/.td` и вложенных `.cbi-section`. Они сжимали строки, разрывали колонки, наслаивали кнопки и создавали пустые области.

Новая система сохраняет штатную структуру LuCI: HTML `<table>` и flex-таблицы `.table` оформляются отдельно; поля — только внутри непосредственных CBI-строк; сложные таблицы на телефоне получают горизонтальную прокрутку **внутри таблицы**, а короткие таблицы правил с безопасной структурой — карточный вид.

## Установка

**Создайте резервную копию настроек роутера и сохраните SSH-доступ.** Не прерывайте обновление прошивки во время установки темы.

1. Распакуйте архив и скопируйте папку `Allure_Router_OpenWrt25` на роутер в `/tmp`.
2. По SSH выполните:

```sh
cd /tmp/Allure_Router_OpenWrt25
sh install.sh
```

3. Обновите LuCI с очисткой кэша. Не затрагиваются настройки Firewall, WAN и Wi-Fi.

Для установки требуются LuCI (ucode templates), `luci-theme-bootstrap` и `rpcd-mod-ucode`. Установка копирует исходные файлы, а не собирает прошивку.

## Если страница не открывается

Через SSH верните стандартную тему:

```sh
uci set luci.main.mediaurlbase='/luci-static/bootstrap'
uci commit luci
/etc/init.d/uhttpd reload
```

Для полного удаления запустите `sh uninstall.sh` в исходной папке.

## Что осталось из Allure

Сохранены: логотип Allure, боковое меню, иконки, тёмная/светлая/системная темы, анимированный экран входа, главная панель мониторинга, RU/EN, диагностика температуры. Изменяется прежде всего слой оформления обычных страниц LuCI.

## Как проверено

Тема работает на живом роутере Cudy TR3000 (OpenWrt 25.12.5): дашборд, Forkop, сеть, беспроводные интерфейсы, процессы, пакеты, автозапуск, SSH-ключи, резервные копии и настройки системы проверены на ширинах 320, 390 и 1440 px. Скриншоты главной страницы — в `preview/screenshots`.

Ограничение: сторонние приложения с собственным CSS, иной HTML-структурой или iframe могут требовать адаптации.
